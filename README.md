# Фитнес-сводка

Android-приложение, которое читает данные Garmin из **Health Connect** и
складывает их в сводку за день и за неделю: шаги, дистанция, калории, пульс,
сон со стадиями и тренировки.

Ничего не измеряет само, ничего не пишет обратно — только читает и агрегирует.

```
Часы Garmin ──BLE──> Garmin Connect ──> Health Connect ──> Фитнес-сводка
```

## Экраны

| | |
|---|---|
| **День** | Шаги, дистанция, калории, пульс покоя, сон по стадиям, тренировки дня. Стрелками — по датам назад |
| **Неделя** | Итоги недели, сравнение с прошлой, график шагов и сна по дням, тренировки |
| **Тренировки** | Весь архив занятий, сгруппированный по датам |
| **Я** | Разрешения Health Connect, синхронизация, аккаунт, экспорт JSON, обновления |

## Требования

- **Android 14+** — именно с этой версии Garmin Connect умеет писать в Health Connect
- Установленный и синхронизированный **Garmin Connect**
- В Garmin Connect включён Health Connect: *Ещё → Настройки → Подключённые приложения → Health Connect*

Подробнее: [`docs/SETUP_HEALTH_CONNECT.md`](docs/SETUP_HEALTH_CONNECT.md)

## Установка

APK собирается в GitHub Actions при каждом пуше в `main` и публикуется в
**Releases** с тегом `build-<номер>`. Скачать последний APK — вкладка Releases.

Дальше приложение обновляет себя само: **Я → Обновления → Проверить обновления**.

## Сборка локально

```bash
./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

Нужен JDK 17 и Android SDK с платформой **36** (этого требует
`androidx.health.connect:connect-client:1.1.0`; `targetSdk` при этом 35).

## Стек

Kotlin · Jetpack Compose (Material3) · Room · Health Connect · Firebase
Firestore + Auth. Без ViewModel — состояние живёт в Compose поверх Flow из
репозиториев.

Room — единственный источник правды для UI. Health Connect стоит выше по потоку
(источник только на чтение), Firestore — сбоку (синхронизация между
устройствами). Ни один экран не обращается к ним напрямую.

## Облачная синхронизация

Необязательна. Из коробки в репозитории лежит заглушка `google-services.json`, и
приложение работает полностью офлайн. Чтобы синхронизировать между устройствами
— [`docs/SETUP_FIREBASE.md`](docs/SETUP_FIREBASE.md).

## Чего здесь нет и не будет

**Body Battery, Stress, Intensity Minutes, Training Load, VO2max** — это
фирменные метрики Garmin. В Health Connect таких типов данных не существует,
поэтому Garmin их туда не передаёт. Получить их можно только через официальный
Garmin Health API (одобрение для юрлиц + серверный webhook) или неофициальную
авторизацию по логину/паролю — оба варианта осознанно не выбраны, обоснование в
[`CLAUDE.md`](CLAUDE.md).

## Приватность

Данные хранятся на устройстве в Room. В облако (Firestore) уезжают только если
вы явно вошли в аккаунт, и правила доступа (`firestore.rules`) разрешают чтение
и запись строго под своим `uid`.

Приложение не связано с Garmin и не использует Garmin Connect API.
